# 更新记录

## v2.5.4

- 自动分析学习窗口与防抖间隔脱钩：只认约 ≤35ms 的硬件接触抖动；正常快打不再误纳入
- 纳入阈值提高到 5 次，避免偶发误判逐渐变成「弯路全盘」
- 新增 macOS 版（`macos/`，Swift + CGEventTap），与 Windows 版逻辑对齐，需在 macOS 上编译

## v2.5.3

- 高级设置：选键仅鼠标，不再用实体键/空格误触按钮
- 手动选键与自动分析融合：自动纳入的键可用鼠标点选取消或增补
- 去掉「取消」按钮，关窗/确定即保存；退出高级模式请改选「全盘模式」
- 「快捷模式」更名为「全盘模式」

## v2.5.2

- 高级设置页：去掉定时全窗刷新，减少闪烁跳动
- 自动分析：按下/抬起状态机区分接触抖动与系统长按连发，长按连发不再误纳入

## v2.5.1

- 轻量化：钩子热路径改固定数组与 Tick 计时；延迟写注册表；编译 -Os/--gc-sections，体积约 260KB

## v2.5.0

- 高级设置页合并：手动选键 / 自动分析二选一；移出菜单里易误点的自动分析项
- 快捷模式菜单文案与选择说明更完整
- 修复自动分析漏检：改为累计原始抖动（不再被正常间隔清零）；阈值 2 次纳入

## v2.4.3

- 移除高级模式启用复选框；托盘状态缩短

## v2.4.2

- 自动分析只基于原始信号；移出收紧

## v2.4.1

- 完整键盘布局与修饰键 VK 修正

## v2.4.0

- 三选一与自动分析初版
