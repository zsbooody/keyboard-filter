# 更新记录

## v2.5.5

- **修复（macOS）更新/替换版本后授权失效误报**：辅助功能授权绑定应用二进制指纹，版本更新后旧授权记录失效但系统设置开关仍显示打开。现引导窗口会明确提示「移除后重新添加」的恢复步骤，并在 README 增加故障排查说明
- **改进（macOS）权限状态三态显示**：区分「无辅助功能权限」「正在恢复键盘监听（登录初期自动重试）」「正常工作」，不再把监听启动中误报为缺权限
- Windows 版本无功能变化，v2.5.4 构建继续有效

## v2.5.4

- **自动分析学习窗口与防抖间隔脱钩**：只认约 ≤35ms 的硬件接触抖动；正常快打不再误纳入
- **防抖纳入阈值调整**：提高到 5 次抖动纳入，避免偶发误判逐渐累积为「弯路全盘」
- **衰减机制上线**：连续 20 次清洁敲击衰减 1 次异常计数，达到 120 次正常击键自动移出防抖名单
- **重构并发布原生 macOS 版**（`macos/`）：
  - 核心对齐：基于 `CGEventTap` 与 128 键定长数组，毫秒级比对，零堆分配热路径
  - 现代 UI：SwiftUI 打造 80% 紧凑型原生键盘画板，支持深色/浅色模式自适应
  - 交互安全：设置窗口拦截物理按键事件，防止打字测试误触发清空/确定按钮
  - 系统整合：原生状态栏常驻、LaunchAgent 登录自启动管理、辅助功能权限引导向导与自动恢复
  - 单包发布：编译生成独立的 `KeyboardFilter.app`（约 330KB），内嵌高清应用图标
