# 键盘防抖工具 (Keyboard Filter) v2.5.4

轻量、极低开销的跨平台（Windows / macOS）系统托盘/菜单栏键盘防抖工具，基于底层事件挂钩实现，专门过滤机械键盘接触抖动（双击/连击误触）。

## 宣传演示

交互页与约 20 秒短片在 [`promo/`](promo/README.md)。本地预览：

```bash
cd promo && python3 -m http.server 8765
```

打开 `http://127.0.0.1:8765/`。短片 `promo/media/demo.mp4`（约 35 秒，含旁白与配乐）。

## 核心设计哲学

- **极低开销与零感知延迟**：事件钩子热路径采用定长数组与高精度时钟（Windows `GetTickCount64` / macOS `CACurrentMediaTime`），无堆分配、不刷新 UI、不频繁写注册表/磁盘。
- **硬件级智能防抖学习**：自动分析只捕捉硬件接触不良产生的极短回弹抖动（$\le 35\text{ms}$），与业务防抖间隔（如 100ms）严格解耦；系统长按连发（$\ge 180\text{ms}$）自动滤除，正常打字绝不误判。
- **三种工作模式自由切换**：
  1. **全盘模式**：所有按键全局防抖，即开即用。
  2. **手动选键（高级模式）**：通过可视化键盘画板自由点选需要防抖的个别键。
  3. **自动分析（高级模式）**：自动监控原始信号并将频繁抖动的按键纳入防抖，仍支持鼠标随时增减。
- **纯鼠标交互保护**：高级选键窗口接管并吞掉实体键盘输入，用户在当前窗口随意敲击测试也不会误触界面的“清空”或“确定”按钮。
- **即关即存**：不设多余的“取消”按钮，关窗或点“确定”即保存当前选择。

## 工作模式详解

### 1. 全盘模式
全部按键均以当前设定的频率限制阈值进行防抖。日常办公或老旧键盘全面连击时推荐使用。从高级模式切换回全盘模式即可重置所有按键保护。

### 2. 高级设置（手动选键 / 自动分析）
点击托盘/菜单栏的“高级设置”，弹出可视化键盘画板：
- **手动选键**：用鼠标单击想要防抖的键，按键变蓝即代表生效；再次点击即可取消。
- **自动分析**：程序始终在底层监控原始键盘信号（即使已被拦截的键也会记录）。当检测到按键连续出现约 $\le 35\text{ms}$ 的接触抖动累计达 5 次以上，系统自动将该键纳入保护，并在画板上实时点亮。你也可以用鼠标手动剔除误加的键或手动补充按键。
- **平滑衰减机制**：若某按键连续正常敲击 20 次，异常计数自动减 1；达到连续 120 次清洁敲击时自动移出保护列表，保证按键保护名单动态精准。

### 3. 防抖频率设定
提供 4 档开箱即用的预设频率：
- **1次/秒**：1000ms 间隔，强力防抖（适合严重连击键或特殊触发开关）。
- **5次/秒**：200ms 间隔，中等防抖。
- **10次/秒**：100ms 间隔（**默认推荐**），兼顾流畅打字与机械轴回弹抑制。
- **20次/秒**：50ms 间隔，轻微防抖（适合高刷新电竞键盘防微小抖动）。

## 编译与安装

### Windows 版本

需要 MSVC 或 MinGW 工具链：
```powershell
.\build.ps1 -Install
```
编译产物位于 `build/` 目录。

### macOS 版本

在 macOS 终端中运行自动化构建脚本：
```bash
./macos/build.sh
```
构建产物为独立的应用程序：
```bash
dist/KeyboardFilter-macOS/KeyboardFilter.app
```
直接运行或拖入 `/Applications`（应用程序目录）即可。

> **macOS 权限注意**：
> macOS 对全局事件拦截有严格的安全限制。首次打开应用时，程序会自动弹窗引导。请前往 **系统设置 → 隐私与安全性 → 辅助功能** 中勾选 **键盘防抖工具**（KeyboardFilter）。授权通过后状态栏图标将自动变为正常工作状态。
