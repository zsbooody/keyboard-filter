# 键盘防抖工具 (macOS 版本)

基于 Windows 键盘防抖工具 v2.3.3.0 开发的 macOS 版本，提供一致的键盘防抖和按键过滤功能。

## 功能特性

- **键盘防抖**: 过滤机械键盘按键抖动，防止重复输入
- **延迟调节**: 可调节防抖延迟时间 (10-200ms)，适应不同键盘
- **按键过滤**: 过滤特定按键，支持自定义按键代码
- **频率限制**: 限制每秒按键次数，防止快速连击
- **开机自启动**: 开机自动运行
- **设置保存**: 自动保存用户设置
- **图形界面**: 简洁的 SwiftUI 界面，易于使用

## 系统要求

- macOS 11.0 (Big Sur) 或更高版本
- 64位 Intel 或 Apple Silicon 处理器
- 需要辅助功能权限 (用于监听键盘事件)

## 安装和使用

### 1. 构建应用

```bash
# 进入项目目录
cd KeyboardFilterMac

# 运行构建脚本
./build.sh
```

构建完成后会生成可执行文件 `KeyboardFilterMac`。

### 2. 首次运行

1. 运行应用:
   ```bash
   ./KeyboardFilterMac
   ```

2. **重要**: 首次运行时需要授予辅助功能权限:
   - 系统会提示需要"辅助功能"权限
   - 点击"打开系统设置"按钮
   - 在"安全性与隐私" → "隐私" → "辅助功能"中启用本应用
   - 关闭应用后重新启动

### 3. 使用说明

- **主界面**: 显示监听状态、权限状态和按键统计
- **设置界面**: 点击"打开设置"按钮进行详细配置
- **基本设置**: 调节防抖延迟、频率限制、开关功能
- **按键过滤**: 添加需要过滤的特定按键
- **自启动**: 启用后应用会在登录时自动启动

## 技术实现

### 键盘事件监听
使用 macOS 的 `CGEventTap` API 监听系统级键盘事件:
- 监听键盘按下和释放事件
- 实时过滤和处理按键
- 需要辅助功能权限

### 防抖算法
1. **时间间隔检查**: 记录每个按键的最后触发时间
2. **延迟过滤**: 如果两次相同按键的间隔小于设定值，过滤第二次按键
3. **频率限制**: 统计每秒按键次数，超过限制时过滤后续按键

### 启动项管理
通过 `LaunchAgents` 实现开机自启动:
- 在 `~/Library/LaunchAgents/` 创建 plist 文件
- 用户级启动，不需要管理员权限

## 常见问题

### Q: 应用无法监听键盘事件
**A**: 检查是否已授予辅助功能权限。在"系统设置" → "隐私与安全性" → "辅助功能"中启用本应用。

### Q: 按键过滤不生效
**A**:
1. 确保"启用按键过滤"开关已打开
2. 检查要过滤的按键代码是否正确
3. 尝试重启应用

### Q: 如何查看按键代码？
**A**:
1. 运行应用时查看控制台输出
2. 按下按键时，应用会记录按键代码
3. 或使用第三方工具查看键盘按键代码

### Q: 如何卸载？
**A**:
1. 删除可执行文件 `KeyboardFilterMac`
2. 删除设置文件: `~/Library/Preferences/com.keyboardfilter.mac.plist`
3. 删除启动项: `~/Library/LaunchAgents/com.keyboardfilter.mac.app.plist`
