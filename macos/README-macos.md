# 键盘防抖工具 macOS 版 v2.5.4

与 Windows 版功能对齐的菜单栏小工具（CGEventTap 实现，Swift 单文件）。

## 功能

- 全盘模式：全部按键防抖
- 高级设置：手动选键 / 自动分析（同一页，仅鼠标点选增减，只有「确定」，关窗即保存）
- 自动分析：只看原始信号；系统长按连发不纳入；仅 ≤35ms 接触抖动计入，累计 ≥5 次纳入
- 频率：1/5/10/20 次每秒

## 编译（需在 macOS 上）

```bash
cd macos
./build.sh
```

产物在 `dist/KeyboardFilter-macOS/keyboard_filter`。

## 权限

首次运行需在 系统设置 → 隐私与安全性 → 辅助功能 中允许本程序，否则事件挂钩创建失败并弹窗提示。
