# 键盘防抖工具 macOS 版本 - 问题修复说明

## 修复的问题

### 1. 设置按钮无反应
**问题描述**: 点击主界面的"打开设置"按钮无任何反应。
**根本原因**: 使用了错误的API调用 `showSettingsWindow:`，在macOS 11.0-12.x中应该使用 `showPreferencesWindow:`。
**解决方案**: 添加版本检查，为不同macOS版本使用正确的API：
```swift
if #available(macOS 13.0, *) {
    NSApp.sendAction(Selector(("showSettingsWindow:")), to: nil, from: nil)
} else {
    NSApp.sendAction(Selector(("showPreferencesWindow:")), to: nil, from: nil)
}
```

### 2. 设置页面布局问题
**问题描述**: 设置页面第一页占比不正确，部分内容在页面外显示不全。
**根本原因**:
1. SettingsView内部设置了固定的`.frame(width: 500, height: 550)`，与Settings场景的`.frame(width: 400, height: 500)`冲突
2. 内容过多时没有滚动支持
**解决方案**:
1. 移除SettingsView内部的frame设置
2. 调整Settings场景的frame为弹性尺寸：
   ```swift
   .frame(minWidth: 500, idealWidth: 500, maxWidth: 600,
          minHeight: 550, idealHeight: 550, maxHeight: 700)
   ```
3. 为每个tab页添加ScrollView容器，支持内容滚动

### 3. 权限状态更新不及时
**问题描述**: 在系统设置中授予辅助功能权限后，应用不能及时反应，需要重启软件。
**根本原因**: 权限检查只在应用启动时执行一次，没有实时监控权限状态变化。
**解决方案**:
1. 在KeyboardMonitor中添加`refreshAccessibilityPermission()`方法
2. 在ContentView中添加定时器，每2秒检查一次权限状态：
   ```swift
   @State private var timer = Timer.publish(every: 2.0, on: .main, in: .common).autoconnect()
   ```
3. 添加应用激活通知监听，当应用从后台返回前台时检查权限
4. 在视图出现时立即检查权限

## 技术实现细节

### 权限状态实时更新机制
1. **定时检查**: 每2秒自动检查一次权限状态
2. **应用激活检查**: 应用从后台激活时立即检查
3. **视图出现检查**: 每次界面显示时检查
4. **权限请求后延迟检查**: 请求权限后1秒检查结果

### 设置界面优化
1. **弹性布局**: 使用min/ideal/max尺寸代替固定尺寸
2. **滚动支持**: 所有tab页内容支持垂直滚动
3. **间距优化**: 使用`Spacer(minLength: 20)`确保底部间距
4. **内边距统一**: 保持一致的padding设置

### 兼容性处理
1. **API版本适配**: 针对不同macOS版本使用对应的设置窗口API
2. **SwiftUI版本适配**: 使用兼容的Alert和Button样式
3. **架构兼容**: 保持x86_64架构，支持Intel和Apple Silicon（通过Rosetta 2）
