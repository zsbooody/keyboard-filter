# 键盘防抖工具 (macOS 版) v2.5.4

专为 macOS 设计的超轻量系统菜单栏键盘防抖小工具。基于 Apple 底层 `CGEventTap` API 与现代 SwiftUI 紧凑 80% 键盘画板构建，逻辑与 Windows v2.5.4 版完全对齐。

---

## 功能特性

- **菜单栏轻量常驻**：原生 `NSStatusItem`，状态栏动态显示当前状态（例如 `键盘防抖 · 全盘 · 10/秒`、`手动(3)`、`自动(1)`）。无 Dock 栏图标打扰。
- **三种工作模式**：
  - **全盘模式**：所有按键防抖，即开即用。
  - **手动选键**：在 80% 键盘画板上点选需要防抖的按键（按键呈系统强调色高亮）。
  - **自动分析**：底层分析物理接触抖动，自动点亮纳入抖动按键，同时支持鼠标自由微调。
- **硬件级智能学习机制**：
  - 只判定 $\le 35\text{ms}$ 的硬件级物理接触抖动，彻底脱离软件防抖阈值（快打绝不误判）。
  - 过滤系统连发按键（`keyboardEventAutorepeat` 及按住超 180ms 区域完全放行）。
  - 累计 $\ge 5$ 次抖动自动加入防抖名单；每 20 次正常击键自动衰减 1 次，连续 120 次正常击键自动解除防抖。
- **纯鼠标配置交互**：
  - 设置窗口由 `KeySwallowingWindow` 承载，屏蔽所有实体按键事件。即使在设置窗口中疯狂敲击测试按键，也不会误触发“清空全部”或“确定”按钮。
  - 无冗余“取消”按钮，关窗或点“确定”即保存当前设定。
- **开机自启动**：
  - 遵循 macOS 规范，基于 `~/Library/LaunchAgents/com.keyboardfilter.mac.app.plist` 实现登录时静默启动。
- **事件挂钩自动容错**：
  - 当系统发生卡顿或高负载导致 macOS 临时挂起 EventTap 时，自动监听 `tapDisabledByTimeout` / `tapDisabledByUserInput` 并无缝重新唤醒。

## 系统要求

- macOS 12.0 (Monterey) 或更高版本
- Apple Silicon (M1/M2/M3/M4) 或 Intel 64位处理器
- 需要授予系统「辅助功能」权限（用于监听并拦截硬件键盘事件）

---

## 编译与打包

本项目使用原生 Swift 编写，不引入任何第三方庞大依赖。

在项目根目录下或 `macos/` 目录运行：
```bash
./macos/build.sh
```

构建脚本会自动：
1. 探测本机 Command Line Tools / Xcode macOS SDK。
2. 启用 release 级优化编译所有 Swift 源文件。
3. 组装标准 macOS App Bundle (`KeyboardFilter.app`)。
4. 注入 `LSUIElement=true` 保证应用仅常驻顶部菜单栏。
5. 嵌入应用高清图标资源 `AppIcon.icns`。

最终打包产物位于：
```
dist/KeyboardFilter-macOS/KeyboardFilter.app
```

## 安装与首次使用引导

### 1. 运行应用
可以直接在终端执行：
```bash
open dist/KeyboardFilter-macOS/KeyboardFilter.app
```
或者将 `KeyboardFilter.app` 复制/移动到系统的 `/Applications` 文件夹中双击运行。

### 2. 授权「辅助功能」权限
由于键盘事件拦截属于 macOS 系统高特权 API：
1. 首次打开应用时，屏幕中央会弹出“需要辅助功能权限”的引导窗口。
2. 点击引导窗口上的 **“打开系统设置”** 按钮（或手动打开 **系统设置 → 隐私与安全性 → 辅助功能**）。
3. 在辅助功能列表中找到 **键盘防抖工具**（或 `KeyboardFilter`）并打开开关。
4. 授权成功后，无需重启程序，状态栏的警告图标（⚠️）会自动切换为正常的键盘图标（⌨️），应用即刻开始工作。

### 3. 操作菜单说明
点击顶部菜单栏的键盘小图标，即可唤出控制菜单：
- **状态栏摘要**：展示当前模式、已纳防抖键数以及当前防抖频率。
- **全盘模式**：勾选后所有按键均按设定的时间间隔防抖。
- **高级设置…**：打开 SwiftUI 80% 紧凑键盘画板，进行鼠标点选或查看自动学习到的按键。
- **防抖频率**：
  - 1次/秒 (强力防抖，间隔 1000ms)
  - 5次/秒 (中等防抖，间隔 200ms)
  - 10次/秒 (默认防抖，间隔 100ms，**推荐**)
  - 20次/秒 (轻微防抖，间隔 50ms)
- **开启/关闭自启**：一键配置登录自启动服务。
- **测试防抖效果**：点击后根据当前所选模式弹出针对性测试指引。
- **退出**：保存所有当前设置并优雅退出。
